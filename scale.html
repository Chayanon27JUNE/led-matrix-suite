2 คุมมุมกล้องสไลซ์ด้วย camRig

กล้องทั้ง N ตัวถูกทำให้เป็นลูกของ null ตัวเดียว (camRig) → ขยับ/หมุน rig ตัวเดียว กล้องตามทั้งชุดโดยที่ระยะ slab ยังเรียงถูก ซ้าย = มองจากด้านบน เห็น scene กับ "กล่องที่กล้องจับ" · ขวา = สิ่งที่ไปโผล่ในก้อน LED

มุมบน (แกน X-Z) · กรอบฟ้า = พื้นที่ที่กล้องสไลซ์จับได้
ก้อน LED มองจากด้านบน · เม็ดที่ติด = จุดที่ตกอยู่ในกรอบ
ortho ไม่มี "ถอยกล้อง" — กล้อง ortho ระยะห่างไม่มีผลกับขนาดภาพเลย สิ่งที่ทำหน้าที่ถอย/เข้าใกล้คือ Zoom ซึ่งคุม orthowidth + near/far + tz พร้อมกัน (ถ้าคุมแค่ orthowidth แกนลึกจะไม่ย่อตาม → สัดส่วนเพี้ยน)
near = (me.digits-1) * (Zoom / Layers)      far = (me.digits) * (Zoom / Layers)
tz   = Zoom * 0.5                          orthowidth = Zoom
camRig:  tx = Panx   ty = Pany   tz = Depth   rx/ry/rz = Rotx/Roty/Rotz

4 จัดก้อน LED ให้อยู่กลาง origin
🖱️ ลากเพื่อหมุน · เส้นไขว้ = origin (จุดที่กล้อง preview หมุนรอบ)

posTOP เขียนตำแหน่งเริ่มที่ (ix+0.5)·pitch → ก้อน LED กิน 0 → 4.5 ทั้งแกน X และ Z แปลว่า มุมกล่องอยู่ที่ origin ไม่ใช่จุดกึ่งกลาง กล้อง preview ที่ orbit รอบ origin เลยเห็นก้อนเยื้องตลอด

x -= float(NX)    * 0.5 * uPitch.x;   // NX = pixel ต่อชั้น
y -= float(H - 1) * 0.5 * uPitch.y;   // H  = Height
z -= float(NZ)    * 0.5 * uPitch.x;   // NZ = จำนวนชั้น

6 Gotcha ที่เจ็บมาแล้ว
💥
.eval() บน OP-path param ลาก cook ทั้งสาย

📐
