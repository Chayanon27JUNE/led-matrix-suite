6 วิธีฉีดสีทดสอบโดยไม่พังของเดิม

แทรก switchTOP ก่อน flip1 เพื่อสลับระหว่างเนื้อหาจริงกับสีทดสอบ — กลับคืนได้ทันทีด้วยการเปลี่ยน index

src_switch = switchTOP    in0 = soptotop/out1 · in1 = red_test
flip1.inputConnectors[0].connect(src_switch)

src_switch.par.index = 1   # → แดงล้วนทั้งจอ
src_switch.par.index = 0   # → กลับไปใช้เนื้อหาเดิม
